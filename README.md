## 导入脚本

在 Scripting 中导入需要的项目目录地址。例如 GitHub Actions 管理：

```text
https://github.com/Zerolost/scripting-script/tree/main/github-actions
```

各项目目录直接包含 `script.json` 和运行入口。后续脚本也会放到各自目录，并在这里添加索引。
