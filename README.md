# Scripting Script

Scripting app 的脚本集合。

## 项目索引

| 项目 | 介绍 | 文档 |
| --- | --- | --- |
| GitHub Actions 管理 | 查看工作流与任务步骤、触发运行，支持桌面小组件和外观调试 | [使用说明](github-actions/README.md) |
| 模块坞 ModuleDock | Surge / Loon / Stash / Shadowrocket 本地模块批量更新、从链接安装、反劫持模块 | [使用说明](ModuleDock/README.md) |

## 导入脚本

在 Scripting 中导入需要的项目目录地址。各项目目录直接包含 `script.json` 和运行入口。

GitHub Actions 管理：

```text
https://github.com/Zerolost/scripting-script/tree/main/github-actions
```

模块坞 ModuleDock：

```text
https://github.com/Zerolost/scripting-script/tree/main/ModuleDock
```
